# AI-Интервьюер: Голосовой тренажер для подготовки к IT-собеседованиям

AI-Интервьюер — это веб-приложение, симулирующее процесс технического собеседования. Система принимает голосовые ответы пользователя, транскрибирует их в текст, анализирует корректность с помощью локальной LLM и генерирует следующий вопрос, озвучивая его сгенерированным голосом с использованием передовых технологий клонирования и дизайна голоса.

Проект разработан с микросервисной архитектурой и предназначен для локального развертывания с использованием GPU.

## 🛠 Технологический стек

**Инфраструктура и логика:**
* **Бэкенд:** FastAPI (Python) — асинхронный оркестратор ML-моделей.
* **Фронтенд:** Streamlit — легковесный UI с поддержкой записи аудио из браузера.
* **Контейнеризация:** Docker, Docker Compose.

**Нейросетевой пайплайн:**
1. **STT (Speech-to-Text):** `openai/whisper-small` — точное распознавание речи кандидата.
2. **LLM (Large Language Model):** `Qwen/Qwen2.5-1.5B-Instruct` — анализ ответов, генерация фидбека и новых вопросов (выступает в роли Senior-интервьюера).
3. **TTS (Text-to-Speech):** `k2-fsa/OmniVoice` — новейшая диффузионная модель синтеза речи. Поддерживает **Voice Design** (создание голоса по текстовому описанию, например, "female, professional, calm") и **Zero-shot Voice Cloning** (клонирование голоса по короткому аудиосэмплу).

## ⚙️ Функционал приложения

* **Голосовое взаимодействие:** Полностью речевой интерфейс. Пользователь отвечает голосом, система отвечает голосом.
* **Кастомные голоса HR-ов:** Возможность настраивать пол, акцент и стиль речи интервьюера без необходимости поиска подходящих датасетов, или даже клонировать голос реального человека.
* **Анализ ошибок:** ИИ указывает на неточности в ответе кандидата перед тем, как задать следующий вопрос.
* **Адаптивность:** Модель генерирует вопросы на основе контекста диалога, а не берет их из жестко заданной базы.

## 🚀 Установка и запуск

### Требования
* ОС: Linux (Ubuntu/Arch) или WSL2 под Windows.
* Установленный Docker и Docker Compose.
* Видеокарта NVIDIA (от 8 ГБ VRAM) и установленный NVIDIA Container Toolkit для проброса GPU в контейнеры.

### Локальный запуск через Docker

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/ai-interviewer.git
   cd ai-interviewer
   ```

2. Соберите и запустите контейнеры:
   ```bash
   docker-compose up --build -d
   ```

3. Откройте приложение в браузере:
   * Фронтенд (Streamlit): `http://localhost:8501`
   * Документация API (Swagger UI): `http://localhost:8000/docs`

## 🕹 Как использовать приложение

1. Откройте интерфейс Streamlit.
2. Выберите грейд (Junior/Middle/Senior) и направление (например, Python Backend) в боковом меню — это обновит системный промпт LLM.
3. (Опционально) Задайте характер голоса интервьюера текстовым промптом.
4. Нажмите кнопку **"Начать собеседование"**. Система сгенерирует и озвучит первый вопрос.
5. Нажмите на иконку микрофона и запишите свой ответ.
6. Нажмите **"Отправить"**. Дождитесь ответа: на экране появится транскрибация вашего ответа, текст фидбека от ИИ и аудиоплеер с голосом интервьюера, задающим следующий вопрос.

## 🧪 Тестирование

Для запуска автотестов выполните команду внутри контейнера бэкенда:
```bash
docker exec -it ai_backend pytest /app/tests/ -v
```
Тесты проверяют доступность API, корректность структуры JSON-ответов и обработку аудио.
